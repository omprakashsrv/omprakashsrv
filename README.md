### 🔧 Highlights

- **Ampairs, a multi-tenant business platform.** A modular Spring Boot monolith with 25 domain modules, workspace-based multi-tenancy, device-aware JWT auth, RBAC, versioned REST APIs and event delivery over WebSocket. Clients are built with Angular and Compose Multiplatform (Android, iOS, Desktop).
- **AI-native development.** Ampairs is built with a spec-driven workflow (spec → plan → tasks → implementation) using AI coding agents, with enforced architecture rules and an on-device AI assistant module.
- **Reactive and distributed systems.** Reactive batch processing (Spring WebFlux, R2DBC), monolith-to-microservices migration, adaptive throttling, and deep production troubleshooting across the JVM, connection pools and databases.
- **Fintech and eSign platforms.** Enterprise eSign, KYC and document platforms, a zero-knowledge PII vault with envelope encryption for data-protection compliance, and a modular customer-facing Android SDK.
